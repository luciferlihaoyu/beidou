# 北斗 写作平台优化方案

> 范围：基于当前 master `975a465` 的代码现状（14 个数据模型、11 个技能卡、6 个前端页面），对标 Notion / Obsidian / Scrivener / 番茄写作 / 彩云小梦 / 飞书文档，提出的分阶段优化建议。
>
> 不改即存 UX 假设：定位是「**单作者长篇网文**的 AI 协作写作平台」——多卷 + 多章 + 资料库 + AI 续写/审查/灵感。所以优化方向优先于：**沉浸式写作、AI 协作、知识库联动、写作目标与数据**，其次是协作 / 平台化。

---

## TL;DR — 优先级

| 阶段 | 主题 | 目标 |
|---|---|---|
| **P0 立刻**（1-2 周） | 打字体验打磨、章节标签可视化、统计热力图 | 让"码字"动作本身**顺滑、不打断** |
| **P1 短期**（3-6 周） | 资料库（璇玑/AList 导入）真正"用起来"、大纲重做、AI 续写工作流 | 把已建但散落的能力**串成一条流水线** |
| **P2 中期**（2-3 月） | 目标/日更/打卡系统、专注模式 2.0、版本对比 | 引入"养成"机制，提升日活和留存 |
| **P3 长期**（3-6 月） | AI 协作大改（流式 + 选中文本操作）、协作/评论、导出出版级 | 从"工具"升级为"平台" |

## 一、打字 / 编辑器（P0，最影响留存）

> 现状：`TiptapEditor`（Tiptap 富文本），左栏章节列表 + 主区编辑 + 右栏 AI 面板。

### 1.1 「写作沉浸感」缺失的细节
- **打字机模式**：编辑时当前行/当前段落高亮（番茄写作/Notion Focus Mode）—— Tiptap ProseMirror 可加 Decoration
- **护眼色温**：自定义背景色 / 纯黑 / 羊皮纸色 / 绿底（Obsidian/Notion）
- **字体选择**：宋体（默认）、楷体（古风）、思源宋体（出版物）、JetBrains Mono（码字仪式感）
- **打字机声音 / 机械键盘音效（可选）**
- **行高 / 段距 / 每行字符数** 实时调整

### 1.2 自动保存 / 异常保护
- **每 5 秒检查变更**（已有 snapshot_service，但触发需手动）→ 改为**输入即触发 dirty**，失焦 / 30 秒空闲自动保存
- **冲突提示**：网络断开时本地缓存，恢复后合并（IndexedDB 暂存）
- **崩溃恢复**：上次编辑内容快照在 sessionStorage

### 1.3 富文本能力弱（必须升级）
- **插入式块**：人物卡引用 `{{char:小明}}` 双向链接到 `Character` 表
- **代码块 / 注释块 / 引用块**：写作常见（场景描述 / 章节备注 / 引用典故）
- **图片**：直接拖图 / 截图粘贴 → 上传到 AList，编辑器引用 URL（用现有 `AList` 集成）
- **表格**：势力关系 / 时间线 / 设定对照表（Notion 强项）
- **目录树**：长章节内置大纲（Word 的导航窗格）

### 1.4 块级操作（对标 Notion）
- 鼠标 hover 块左侧出现「拖拽 + / ⋯」操作条
- `/` 命令面板：输入 `/人物` 自动插入人物卡引用、`/大纲` 插入大纲节点
- 选中文字浮工具条：AI 改写 / 解释 / 翻译 / 替换

## 二、统计 / 数据（P0 + P1）

> 现状：`WritingStat` 已有，daily/weekly 接口在 `stats.py`，`goal` 字段在 `Novel`。**有数据但可视化弱**。

### 2.1 数据采集增强（P0）
- **详细会话记录**：每段写作（开始时间、结束时间、字数变化、打字速度、撤销次数、停留时长）→ `WritingSession` 表
- **键入速度曲线**：分钟级 KB/min 折线图（vs 番茄钟统计 4min/12min 节律）
- **删字数 / 净增字数**：分别统计（番茄写作核心指标）
- **番茄钟集成**：内置番茄钟，每 25min 一个番茄，统计番茄数

### 2.2 可视化（P0）
- **热力图**：日历式全年热力图（GitHub 风格）——**已部分实现**（DailyStat），需美化
- **趋势图**：日 / 周 / 月字数折线；卷跨度、章均字数、完稿率
- **目标进度环**：日目标 3000 / 周 20000（圆环进度）
- **今日数据条**：底部状态栏常驻：今日字数 · 目标进度 · 番茄数 · 当前码字速度
- **里程碑徽章**：连续 7 天 / 累计 10 万字 / 完本等（番茄成就体系）

### 2.3 排行榜 / 自比（P1）
- **本月 vs 上月**：自动对比，激励
- **本卷 vs 上卷**：完本前后的产出对比
- **相同字数同日作者对比**（隐私保护下，纯字数）

## 三、易用性 / 平台骨架（P0 + P1）

### 3.1 导航（P0）
- **全局命令面板**（`Ctrl/Cmd + K`）：搜章节、人物、设定、卷、跳转；做动作"新建章节 / 备份 / 切 AI 模型"
- **面包屑**：卷 > 章节 > 段落（点跳大纲）
- **大纲侧栏可折叠**：左侧栏除卷/章外，加"人物 / 设定 / 伏笔 / 大纲" tab（已有但弱）

### 3.2 快捷键（P0）
- `Ctrl+B/I/U` 粗体/斜体/下划线
- `Ctrl+K` 命令面板
- `Ctrl+S` 手动保存
- `Ctrl+Shift+S` 立即快照
- `Ctrl+Enter` AI 续写
- `Ctrl+Shift+F` 全文搜索
- `F11` 沉浸模式（全屏 + 隐藏所有 chrome）
- `Esc` 退出沉浸
- **`?`** 弹快捷键速查

### 3.3 移动适配（P1）
- **响应式**：当前书架/编辑器在窄屏折断，可加**手机版编辑器**（简化工具栏、AI 面板抽屉化）
- **PWA**：离线缓存章节、IndexedDB 暂存未同步
- **触屏优化**：长按弹操作菜单（拖块、引用、查人物卡）

### 3.4 通知 / 提示降噪（P1）
- 全局 toast 收敛到右下角，重要操作（备份完成、AI 报错）可上浮
- 减少 API 报错的 console 噪声（前端 axios 拦截 + 折叠同 message）
- AI 流式输出异常时显示"已暂停，可继续"

## 四、功能性 / 知识库联动（P1，最大价值区）

> 现状：`Character` / `WorldviewEntry` / `Foreshadowing` / `OutlineNode` 4 个表都有 CRUD（`settings.py`），但**散在 NovelSettings 页面**，写正文时调不出来。

### 4.1 右栏"知识舱"（核心升级）
- **替代 / 增强 AI 面板**：右栏加 tab：**AI 助手 / 知识舱 / 笔记 / 快照**
- **知识舱**：根据当前章节光标位置**自动推荐相关**人物 / 设定 / 伏笔（语义匹配）
- **点人物卡** → 浮窗看完整设定 + 出现在哪些章节 + 关系网
- **点伏笔** → 浮窗看埋设位置 + 状态（待回收/已回收/已废弃）
- **新建即用**：知识舱可一键插入到正文 `{{char:小明}}` 块引用

### 4.2 大纲重做（对标 Scrivener corkboard）
- **卡片视图**：每章一张卡片，显示标题/字数/状态/标签/摘要
- **拖拽排序**（已有 reorder API，可视化升级）
- **白板视图（Canvas）**：多线叙事 / 多 POV 排布（Obsidian Canvas 风格）
- **大纲节点 → 章节映射**：OutlineNode 关联 Chapter（已有 _novel_context 提到）

### 4.3 伏笔追踪升级
- **伏笔时序图**：埋设章节 / 计划回收章节的甘特图
- **自动检测**：扫描正文关键词/人物名，建议埋设（AI 辅助）
- **回收提醒**：写作目标章节接近计划回收点时浮窗提醒

### 4.4 资料库（Library）"真正用起来"
- **导入璇玑文档一键关联到卷**（已有，需 UI 流程化）
- **导入 AList 文件**（已有 `upload` 端点，UI 入口浅）
- **资料库搜索 / 引用**：写作时全局搜资料库，插入到章
- **资料卡自动摘要**（AI 摘要 + 标签建议，已部分实现）

## 五、AI 协作（P1 + P2，最大差异化）

> 现状：11 个技能卡、chat/action 流式、AIPanel 已支持 config 切换、focus_mode 已可用。

### 5.1 选中文本操作（P1 重要）
- **选中段落 → 浮工具条**：改写 / 解释 / 翻译 / 润色 / 拉长 / 缩短 / 改视角
- **AI 改写 Diff 视图**：AI 输出与原文并排，可单句接受 / 拒绝 / 全部替换
- **对比多个候选**：同一段选 3 个模型各出 1 改写，对比择优

### 5.2 续写工作流（已有，需打磨）
- **三档续写**：快（500 字）/ 标（1000 字）/ 长（2000 字）
- **接受 / 拒绝 / 插入到光标 / 重写（重新生成）**
- **续写时打 tag**：标记哪段是 AI 写的，方便回溯
- **续写一致性检查**：续写前自动调 consistency-checker 技能卡，发现冲突先警告

### 5.3 灵感便签（P1）
- **悬浮便签**：写作时随时记灵感，自动按时间排
- **AI 整理**：定时让 AI 把便签聚类成大纲节点 / 人物卡
- **灵感墙**：Bookshelf 页加"灵感墙"视图

### 5.4 AI 长上下文（P2）
- **整卷上下文**：写新章时给 AI 喂"上 N 章" + 整卷大纲
- **跨卷引用**：自动注入相关伏笔 / 人物卡
- **可调上下文深度**：用户在 AI 面板选"短（3 章）/ 中（一卷）/ 长（全书）"

### 5.5 AI 模型管理（P0 已修，再补）
- ✅ 已支持：拉取模型 / config 切换 / 拉取不重输 key
- **新需求**：模型对比 / 评分（用户给每条 AI 回复打星，自动统计模型质量）
- **新需求**：模型降级（主模型挂掉自动切备用 config）
- **新需求**：成本追踪（每次 AI 调用 token 数 × 单价 → 日 / 月成本）

## 六、平台化（P2 / P3）

### 6.1 协作（P2）
- **章节评论**：编辑/读者角色区分；点某段加评论
- **版本对比**：两快照之间 diff 高亮
- **共享只读链接**：作家发"作品预览"给读者 / 编辑

### 6.2 模板 / 市场（P2）
- **模板市场**：开篇模板 / 升级流模板 / 题材大纲模板（玄幻/都市/历史）
- **技能卡市场**：用户自定义 prompt → 发布到市场

### 6.3 出版级导出（P2）
- 当前 `export.py` 是简单 zip；升级为：
  - **TXT / DOCX / EPUB / PDF** 多格式
  - **排版模板**：出版书 / 网文平台 / 公众号 排版规范
  - **多卷合一本**

### 6.4 数据迁移（P2）
- **从 Scrivener 导入**（.scriv XML）
- **从橙瓜 / 作家助手 / WPS 导入**（常见格式）
- **从 Markdown / DOCX 导入**（已有 export，反向）

### 6.5 多端同步（P3）
- **WebDAV 同步**（已有 AList 集成可复用）
- **桌面端**（Electron 打包）
- **移动端**（PWA + 离线）

## 七、性能 / 工程（P1 长期）

- **全文搜索**：当前 `search.py` 简单 LIKE → 升级 **FTS5 虚拟表**（SQLite 原生全文索引）
- **章节大文件**：长章（>50k 字）渲染卡 → **分块渲染**（虚拟滚动）
- **AI 流式超时**：当前 60 秒硬超时 → 自适应（按 provider 配）
- **前端代码分割**：当前打包 500kB → 按页 + 按 AIPanel 懒加载
- **SQLite 升级**：考虑迁移到 PostgreSQL（多端 / 备份需要）

---

## 八、首批建议落地的 5 个改进（每项 1-3 天）

按 ROI 排序：

1. **章节内块引用 `{{char:…}}` / `{{setting:…}}` 浮卡预览**（1 天）—— 把已有 Character/WorldviewEntry 表"用起来"，立竿见影
2. **Ctrl+K 命令面板**（2 天）—— 全局搜索 + 新建 / 跳转 / 切 AI 模型，提升专业感
3. **底部状态栏：今日字数 / 进度 / 番茄数**（0.5 天）—— 已有 WritingStat，加 UI 即可
4. **快捷键 `Ctrl+B/I/U/K/S/Enter/F11/?`**（1 天）—— Tiptap 已支持基础，加键位即可
5. **AI 选中文本操作工具条**（2 天）—— 浮工具条 + Diff 视图，最大化 AI 协作价值

合计 **~7 天**（1.5 周），可将北斗从"可用的写作工具"提升为"专业 AI 写作工作台"。
